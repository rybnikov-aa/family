# HR-002: Именование и идентификаторы документов

- **Статус:** действует
- **Источник правила:** правило 17 в `AGENTS.md`.

## Требования

- **HR-002.1** ADR, CJ, FR, NFR и HR записи хранятся по одной записи в отдельном Markdown-файле внутри соответствующего `docs/<type>/` каталога.
- **HR-002.2** Файл имеет вид `<prefix>-xxx-short-name.md`: префикс — `adr`, `cj`, `fr`, `nfr` или `hr`; номер — ровно три цифры `001`–`999`, последовательность независима для каждой категории и не переиспользуется.
- **HR-002.3** `short-name` — английские lowercase ASCII letters `a`–`z`, слова разделяются одиночными дефисами; цифры, кириллица, underscore и иные символы запрещены.
- **HR-002.4** Каждая категория содержит `index.md` с ссылками и traceability на все записи.
- **HR-002.5** ID в тексте соответствует filename; moved/replaced document не получает повторно использованный ID.

## Проверка

Filename regex: `^(adr|cj|fr|nfr|hr)-[0-9]{3}-[a-z]+(-[a-z]+)*\.md$`; сверять непрерывность номеров и индекс перед приемкой.
