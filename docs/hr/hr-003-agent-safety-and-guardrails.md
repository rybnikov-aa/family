# HR-003: Safety requirements for agents

- **Статус:** действует
- **Нормативный источник:** [repository guardrails](../guardrails.md).

## Требования

- **HR-003.1** Все агенты, skills и workflows обязаны соблюдать guardrails; роль или task procedure не может их ослабить.
- **HR-003.2** Не раскрывать production secrets, реальные user credentials, tokens и private keys в коде, docs, logs или output; допустимы только явно локальные dev test accounts.
- **HR-003.3** Сохранять посторонние пользовательские изменения; destructive data, production config/deploy/restart действия выполнять только при явном разрешении на цель/операцию.
- **HR-003.4** Не удалять/перемещать существующие UI-элементы без запроса; перед рискованной операцией проверить target и последствия.
- **HR-003.5** Не заявлять о тесте/проверке/деплое без наблюдаемого результата; сообщать ограничения и факты отдельно от assumptions.
- **HR-003.6** Не создавать commit/branch без явного пользовательского запроса.
- **HR-003.7** Не использовать память вне Git как источник проектных фактов; контекст, необходимый для возобновления работы другим агентом, должен быть записан в принадлежащих ему версионируемых документах.

## Проверка

Сверять рольные профили и skills с `guardrails.md`; при противоречии выполнять более строгую guardrail и сообщать о конфликте.
