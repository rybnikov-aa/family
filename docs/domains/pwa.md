# Спецификация PWA и мобильного режима (family)

## 1. Назначение

PWA-слой делает семейный портал устанавливаемым на телефон, пригодным для повторного
просмотра уже открытых записей и удобным для мобильной загрузки фотографий.

## 2. Требования

- 16.1 Приложение публикует web manifest, standalone display и service worker.
- 16.2 Пользователь может установить приложение из браузера; если браузер поддерживает
  `beforeinstallprompt`, UI показывает явное действие установки.
- 16.3 App shell и ранее просмотренные diary-записи/изображения могут открываться при
  временной потере сети; приватные API-данные не смешиваются между пользователями.
- 16.4 Ввод фотографий с телефона предлагает камеру через `capture="environment"`.
- 16.5 На узких экранах навигация не ломает ширину контейнера и остаётся горизонтально
  прокручиваемой/доступной с клавиатуры.
- 16.6 Настоящие push-уведомления используют отдельный VAPID sender и backend-хранилище
  подписок; browser permission сам по себе push-доставкой не считается.
- 16.7 Подписка и отписка устройства доступны через защищённый API; service worker показывает
  payload и по клику открывает безопасный внутренний URL.

## 3. Критерии приёмки

- [ ] Manifest и service worker присутствуют в production build.
- [ ] Install prompt работает при наличии browser install event.
- [ ] Diary detail/image cache имеет network-first fallback и очищается при logout.
- [ ] Мобильный input фотографий поддерживает camera capture.
- [ ] Push subscription, VAPID sender и cleanup мёртвых endpoint проверены smoke-тестом.
- [ ] `npm run typecheck` и `npm run build` проходят.
