# FR-016: PWA и мобильный режим

- **Статус:** в реализации; Web Push sender — отдельный этап.
- **Акторы:** авторизованный пользователь.
- **Источник:** [domain PWA](../domains/pwa.md).

## Требования

- **FR-016.1** Портал устанавливается как PWA.
- **FR-016.2** App shell и просмотренные diary-записи/изображения доступны при временном offline.
- **FR-016.3** Мобильная навигация и формы адаптированы к узкому экрану.
- **FR-016.4** Загрузка фотографий с телефона поддерживает камеру.
- **FR-016.5** Web Push не считается реализованным без VAPID sender и проверки доставки.

## Проверяемость

Критерии — [domain PWA](../domains/pwa.md), frontend layer и CJ-020.
