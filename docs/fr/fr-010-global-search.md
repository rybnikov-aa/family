# FR-010: Глобальный поиск

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь.
- **Legacy alias:** FR-15 в [domain search](../domains/search.md).

## Требования

- **FR-010.1** Поиск доступен из шапки приложения.
- **FR-010.2** Поиск без учёта регистра находит проекты, задачи и события дневника по названию и краткому описанию.
- **FR-010.3** Результат содержит тип записи, название, описание, метаданные и внутреннюю ссылку.
- **FR-010.4** Результаты доступны через защищённый endpoint; пустой или слишком короткий запрос получает `400`.

## Проверяемость

Критерии и формат результата — [domain search](../domains/search.md) и [API](../layers/api.md).
