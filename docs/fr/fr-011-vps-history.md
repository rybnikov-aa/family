# FR-011: История доступности VPS

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь.
- **Связь:** расширяет [FR-003](fr-003-vps-monitoring.md).

## Требования

- **FR-011.1** После фактической проверки результат VPS сохраняется в историю; ответ из 30-секундного кэша новую точку не создаёт.
- **FR-011.2** Пользователь может открыть историю конкретной VPS за 24 часа, 7 или 30 дней.
- **FR-011.3** История показывает доступность, среднюю задержку, точки состояния и интервалы недоступности.
- **FR-011.4** История хранится в SQLite не более 90 дней и доступна через защищённый endpoint.

## Проверяемость

Критерии хранения, инцидентов и API — [domain VPS](../domains/vps.md) и [API](../layers/api.md).
