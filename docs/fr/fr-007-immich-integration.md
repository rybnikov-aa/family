# FR-007: Интеграция с Immich

- **Статус:** реализовано (настройки подключения и photo picker)
- **Актор:** admin настраивает интеграцию и импортирует фото; авторизованные пользователи могут открыть внешнюю ссылку на архив.
- **Источники:** [Immich guide](../integrations/immich.md), [API](../layers/api.md), [domain diary](../domains/diary.md).

## Требования

- **FR-007.1** Admin задает base URL/API key и проверяет соединение; credentials сохраняются только при успехе.
- **FR-007.2** API key хранится сервером и никогда не возвращается клиенту; GET settings выдает URL и признак configured.
- **FR-007.3** Ссылки «Фотоархив»/«Архив» используют настраиваемый web URL и скрыты, если instance не настроен.
- **FR-007.4** Admin может искать изображения по диапазону дат, просматривать thumbnails, выбирать несколько assets и импортировать оригиналы в событие.
- **FR-007.5** Импорт через backend proxy не раскрывает key браузеру, показывает download progress и загружает в дневник автономные файлы.
- **FR-007.6** Поддерживаются изображения JPG/PNG/WebP/GIF; чрезмерно крупные original и неподдерживаемые MIME не импортируются.
