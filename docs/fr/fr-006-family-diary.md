# FR-006: Семейный дневник

- **Статус:** реализовано
- **Акторы:** авторизованные пользователи читают; admin создает и изменяет события.
- **Источники:** [domain diary](../domains/diary.md), [API](../layers/api.md).

## Требования

- **FR-006.1** Дневник показывает события из отдельной SQLite DB и поддерживает переключение list/card layouts.
- **FR-006.2** События содержат title, дату/период, summary, markdown content, фотографии, cover и уникальную папку хранения.
- **FR-006.3** Список сортируется по дате начала (новые раньше); подробная страница отображает описание, изображения и галерею без дублирования фото, встроенных в текст.
- **FR-006.4** Admin может создать/изменить/удалить событие, управлять cover и fileset; удаление чистит запись и папку файлов.
- **FR-006.5** Markdown editor поддерживает маркеры `diary-image://`, preview, вставку фотографий у курсора, local draft и предупреждение о несохраненных изменениях.
- **FR-006.6** Загрузка ограничена допустимыми типами, 30 файлами и 10 MiB на файл; previews генерируются лениво в WebP.
- **FR-006.7** Фото и API событий доступны только через авторизованный портал; файловые пути защищены от path traversal.
