# FR-002: Профиль и управление учетными записями

- **Статус:** реализовано
- **Акторы:** любой авторизованный пользователь; `admin` для управления другими пользователями.
- **Источники:** [domain auth](../domains/auth.md), [API](../layers/api.md), `frontend/src/pages/ProfilePage.tsx`.

## Требования

- **FR-002.1** Авторизованный пользователь должен иметь возможность менять display name; username и собственную роль через профиль менять нельзя.
- **FR-002.2** Смена собственного пароля должна требовать текущий пароль и новый пароль не короче 6 символов.
- **FR-002.3** Администратор должен иметь возможность просматривать список пользователей, создавать пользователей с ролью `admin` или `user`, задавать пароль и удалять других пользователей.
- **FR-002.4** Admin может принудительно задать пароль без текущего пароля пользователя; удаление собственной учетной записи запрещено.
- **FR-002.5** Username уникален; конфликт создания должен быть представлен как 409 и понятная ошибка формы.
- **FR-002.6** Смена роли существующей учетной записи доступна через `npm run user -w backend -- set-role`; отдельной UI-операции изменения роли нет.

## Проверяемость

Endpoint-level условия и ошибки — [API](../layers/api.md); схема пользователей/сессий и flows — [auth domain](../domains/auth.md).
