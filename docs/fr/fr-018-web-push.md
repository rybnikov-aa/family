# FR-018: Web Push уведомления

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь.
- **Источник:** [domain PWA](../domains/pwa.md).

## Требования

- **FR-018.1** Пользователь может разрешить push-уведомления и зарегистрировать текущее устройство.
- **FR-018.2** Подписки хранятся на backend отдельно для пользователя и устройства; повторная
  регистрация endpoint идемпотентна.
- **FR-018.3** Backend отправляет VAPID-authenticated push-сообщения через отдельный sender.
- **FR-018.4** Service worker показывает уведомление и открывает указанную внутреннюю страницу
  при клике.
- **FR-018.5** Отозванные/истёкшие endpoint удаляются после ответа push-сервиса `404/410`.

## Проверяемость

Контракт подписок и sender — [domain PWA](../domains/pwa.md) и [API](../layers/api.md). UI-путь — CJ-022.
