# FR-009: Планы и задачи

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь читает; `admin` управляет задачами.
- **Legacy alias:** FR-14 в [domain plans](../domains/plans.md).

## Требования

- **FR-009.1** Пользователь видит задачи в группах «К выполнению», «В работе» и «Готово».
- **FR-009.2** Задача содержит название, описание, статус, приоритет, срок и необязательную привязку к проекту.
- **FR-009.3** Администратор может создать, изменить и удалить задачу через UI.
- **FR-009.4** Пользователь может фильтровать задачи по проекту и приоритету.
- **FR-009.5** Задачи хранятся в отдельной SQLite-БД и доступны через защищённый API.

Критерии, валидация и формат API — [domain plans](../domains/plans.md) и [API](../layers/api.md).
