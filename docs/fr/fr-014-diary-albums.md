# FR-014: Альбомы и подборки дневника

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь; управление доступно `admin`.
- **Источник поведения:** [domain diary](../domains/diary.md).

## Требования

- **FR-014.1** Администратор может создавать, переименовывать и удалять альбомы.
- **FR-014.2** Альбом содержит название, описание и набор событий дневника.
- **FR-014.3** Администратор может менять состав альбома без изменения самих событий.
- **FR-014.4** Пользователь может фильтровать дневник по альбому.
- **FR-014.5** Удаление альбома не удаляет события и фотографии.

## Проверяемость

Модель и API — [domain diary](../domains/diary.md) и [API](../layers/api.md). Пользовательский поток — CJ-018.
