# FR-005: Отчетность и документы ремонта

- **Статус:** реализовано
- **Акторы:** авторизованные пользователи читают сводки и документы; admin импортирует и изменяет данные.
- **Источники:** [domain renovation](../domains/renovation.md), [API](../layers/api.md), [ADR index](../adr/index.md).

## Требования

- **FR-005.1** Данные ремонта хранятся отдельно в `renovation.sqlite`; денежные суммы и количества представлены целыми копейками/сотыми.
- **FR-005.2** Сводка должна представлять работы, материалы, план/факт, версии сметы, ведомости и согласованные метаданные объекта.
- **FR-005.3** Admin импортирует PDF через draft → review → confirm; сохраненные документы доступны авторизованным пользователям во встроенном PDF viewer.
- **FR-005.4** Повторный импорт пронумерованного документа заменяет предыдущую версию; документ без номера защищен идемпотентностью type+date.
- **FR-005.5** Дополнительное соглашение сначала формирует предложение/diff; после admin confirmation текущая смета архивируется, новая становится current.
- **FR-005.6** Work и materials reports строятся из БД и доступны отдельными read endpoints; отчеты включают позиции, сводные суммы и ссылки на исходные документы.
- **FR-005.7** Персональные данные заказчика и блоки подписей не публикуются; детали privacy см. guardrails.
