# FR-004: Каталог и пользовательские проекты

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь; admin для CRUD созданных через UI проектов.
- **Источники:** [domain projects](../domains/projects.md), [API](../layers/api.md), `backend/src/config/appProjects.ts`.

## Требования

- **FR-004.1** Список проектов объединяет встроенный реестр и записи БД; сканирование файловой системы не используется.
- **FR-004.2** Пользователь может открыть проект по SPA/hash route; встроенные проекты могут использовать специализированные страницы.
- **FR-004.3** Созданные через UI проекты хранят metadata и markdown content в SQLite; создание не создает файлы и не требует deploy.
- **FR-004.4** Admin может создавать/изменять/удалять только пользовательские записи; встроенные registry entries read-only.
- **FR-004.5** Slug уникален среди registry и DB; поддерживаются ограничения slug, accent, icon и order из domain/API specs.
- **FR-004.6** Список имеет состояния loading/error/empty и упорядочен по `order`, затем по названию.

## Проверяемость

Конкретная схема metadata/content, валидаторы и приемочные сценарии — [domain projects](../domains/projects.md); endpoint formats — [API](../layers/api.md).
