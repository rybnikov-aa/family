# FR-017: Расширенные планы

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь; изменения доступны `admin`.
- **Источник:** [domain plans](../domains/plans.md).

## Требования

- **FR-017.1** Задача может повторяться ежедневно, еженедельно или ежемесячно.
- **FR-017.2** Завершение повторяющейся задачи переводит её в `todo` и вычисляет следующий срок.
- **FR-017.3** Пользователь переключает списочный и календарный режимы.
- **FR-017.4** Просроченные и ближайшие задачи визуально различимы.
- **FR-017.5** При открытом приложении пользователь может разрешить browser reminders для ближайших и просроченных задач.
- **FR-017.6** Настоящая server-side push-доставка не считается реализованной без VAPID sender.

## Проверяемость

API и модель — [domain plans](../domains/plans.md); UI-путь — CJ-021.
