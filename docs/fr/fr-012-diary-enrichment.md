# FR-012: Расширенный дневник

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь; изменения событий доступны `admin`.
- **Источник поведения:** [domain diary](../domains/diary.md).

## Требования

- **FR-012.1** Событие может иметь место, участников и набор тегов.
- **FR-012.2** Пользователь может фильтровать события по году и тегу.
- **FR-012.3** Пользователь может искать события по заголовку, краткому и подробному описанию, месту, участникам и тегам.
- **FR-012.4** Дневник поддерживает режим временной шкалы с группировкой событий по году.
- **FR-012.5** Фильтры и поисковый запрос отражаются в URL страницы дневника.
- **FR-012.6** Администратор редактирует новые поля в существующей форме события.

## Проверяемость

API-фильтры и поля — [domain diary](../domains/diary.md) и [API](../layers/api.md). UI-поведение — CJ-016.
