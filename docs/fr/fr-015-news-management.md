# FR-015: Управляемые новости

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь; управление доступно `admin`.
- **Источник:** [domain news](../domains/news.md).

## Требования

- **FR-015.1** Лента загружает новости из API и показывает только опубликованные записи.
- **FR-015.2** Администратор создаёт, редактирует, закрепляет и удаляет новости.
- **FR-015.3** Новость содержит заголовок, тег, текст, дату публикации и изображения-вложения.
- **FR-015.4** Пользователь может отметить новость прочитанной.
- **FR-015.5** Admin-режим показывает будущие и снятые с публикации записи.

## Проверяемость

Контракт — [domain news](../domains/news.md) и [API](../layers/api.md). Пользовательский путь — CJ-019.
