# FR-013: Экспорт дневника

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь.
- **Источник поведения:** [domain diary](../domains/diary.md).

## Требования

- **FR-013.1** Пользователь может скачать событие в формате JSON или Markdown.
- **FR-013.2** Экспорт содержит metadata события и текстовое описание; секреты и внутренние данные БД не экспортируются.
- **FR-013.3** Пользователь может выбрать фотографии события в галерее и скачать выбранные оригиналы.
- **FR-013.4** Экспорт работает только для авторизованного пользователя и использует безопасные имена файлов.

## Проверяемость

Контракт экспорта — [domain diary](../domains/diary.md) и [API](../layers/api.md). Пользовательский поток — CJ-017.
