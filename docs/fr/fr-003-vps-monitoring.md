# FR-003: Мониторинг и администрирование VPS

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь читает статусы; admin управляет инвентарем.
- **Источники:** [domain VPS](../domains/vps.md), [API](../layers/api.md), `backend/src/services/vpsChecker.ts`.

## Требования

- **FR-003.1** Пользователь должен видеть доступность VPS, агрегированный процент и состояние отдельных сервисов.
- **FR-003.2** Проверка должна различать доступность host и сервисов, поддерживать типы `http` и `ocserv`, возвращать latency/error details.
- **FR-003.3** Результаты GET кэшируются на 30 секунд с in-flight deduplication; явный refresh обходит кэш.
- **FR-003.4** UI должен открывать детализацию, показывать IP, panel URL и сервисы, позволять копировать IP и открывать панель.
- **FR-003.5** Admin может добавлять, редактировать и удалять VPS без перезапуска backend.
- **FR-003.6** Admin может пакетно импортировать JSON; невалидные записи и повторяющиеся имена пропускаются, итог возвращает импортированные/пропущенные записи и ошибки.
- **FR-003.7** VPS entries хранятся в SQLite; конфликты уникального имени и ошибки валидации возвращаются как 4xx.

## Проверяемость

Формулы, пороги, модели хранения, статусы и UI-критерии — [domain VPS](../domains/vps.md); endpoint schema — [API](../layers/api.md).
