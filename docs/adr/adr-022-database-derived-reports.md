# ADR-022: Build renovation reports from database records

- **Статус:** принято

## Контекст

Отчеты по работам и материалам должны отражать актуальные данные приложения и не требовать ручной пересборки HTML.

## Решение

Строить `GET /reports/work` и `GET /reports/materials` на лету из БД.

## Альтернативы

Пересобирать статические HTML-отчеты вручную или с помощью LLM.

## Обоснование и последствия

Статические `Reports/report_*.html` остаются архивом; приложение отображает план/факт, позиции и сводки из БД.
