# ADR-007: Place refresh beside the VPS metric

- **Статус:** принято

## Контекст

Кнопка обновления должна относиться к конкретной метрике и не менять расположение остальных карточек статистики.

## Решение

Размещать «Обновить» внутри карточки рядом со значением.

## Альтернативы

Выделить для кнопки отдельную ячейку grid.

## Обоснование и последствия

Сетка статистики остается стабильной, а действие визуально связано с обновляемой метрикой.
