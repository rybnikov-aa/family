# ADR-006: Use an accessible clickable VPS card

- **Статус:** принято

## Контекст

Карточка должна быть кликабельной и одновременно содержать отдельную кнопку обновления.

## Решение

Оформлять карточку как `<div role="button">`, а не как `<button>`.

## Альтернативы

Использовать `<button>` для всей карточки.

## Обоснование и последствия

Вложенная кнопка обновления остается валидной разметкой; карточка должна сохранять клавиатурную доступность.
