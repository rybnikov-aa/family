# ADR-002: Check VPS availability on the backend

- **Статус:** принято

## Контекст

Проверку нужно выполнять централизованно, с доступом к сети и единым поведением для всех клиентов.

## Решение

Проверять доступность VPS на backend; frontend только отображает результаты.

## Альтернативы

Выполнять проверки из браузера.

## Обоснование и последствия

Backend обеспечивает единую точку проверки, кэширование и доступ к сети из Node.js; UI-компоненты не содержат проверочную логику.
