# ADR-004: Separate host probes from service probes

- **Статус:** принято

## Контекст

Доступный сервер с остановленным прикладным сервисом не должен ошибочно считаться полностью недоступным.

## Решение

IP-проверка использует базовые порты 22/443/80 и дополнительно порты настроенных сервисов.

## Альтернативы

Проверять только порты сервисов.

## Обоснование и последствия

Результат разделяет состояние машины и состояние приложения; доступный хост с недоступным сервисом получает частичную, а не нулевую доступность.
