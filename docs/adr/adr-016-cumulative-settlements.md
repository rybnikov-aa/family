# ADR-016: Use only the latest cumulative settlement act

- **Статус:** принято

## Контекст

Последующие акты взаиморасчетов включают данные предыдущих актов того же типа.

## Решение

В расчете использовать только последний акт каждого типа по `date`.

## Альтернативы

Суммировать все акты.

## Обоснование и последствия

Суммирование дало бы двойной учет; правило реализуется в доменной логике/use case, а не в SQL. Подытог «Подотчетные прораба» уменьшает баланс.
