# ADR-005: Probe ocserv over TCP and DTLS

- **Статус:** принято

## Контекст

TCP-проверка не обнаруживает работающий OpenConnect-сервис, если его UDP/DTLS-канал доступен отдельно.

## Решение

Для ocserv проверять TCP 443 и выполнять UDP/DTLS-пробу.

## Альтернативы

Проверять только TCP.

## Обоснование и последствия

Проверка учитывает транспорт, используемый OpenConnect, и не объявляет сервис недоступным только из-за закрытого TCP-канала.
