# ADR-008: Force VPS refresh with a query parameter

- **Статус:** принято

## Контекст

После явного действия пользователя интерфейсу нужно обойти серверный кэш доступности.

## Решение

`fetchVps(force)` добавляет `?refresh=1`, если запрошена принудительная проверка.

## Альтернативы

Постоянный опрос по таймеру.

## Обоснование и последствия

Проверка выполняется по запросу пользователя, без лишнего фонового трафика.
