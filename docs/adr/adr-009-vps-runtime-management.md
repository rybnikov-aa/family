# ADR-009: Manage VPS from the application

- **Статус:** принято

## Контекст

Изменение состава мониторинга не должно требовать SSH-доступа или ручного редактирования базы.

## Решение

Добавлять VPS через UI и `POST /api/vps`, затем вызывать `reloadVpsEntries()`.

## Альтернативы

Разрешить только ручное изменение SQLite.

## Обоснование и последствия

Администратор управляет списком из приложения; конфигурация в памяти обновляется без перезапуска процесса.
