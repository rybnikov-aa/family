# ADR-012: Use cookie sessions for authentication

- **Статус:** принято

## Контекст

Портал требует входа, отзыв сессии после выхода и безопасную передачу учетных данных без отдельного внешнего сервиса.

## Решение

Использовать httpOnly `SameSite=Lax` cookie-сессии, храня сессии в SQLite.

## Альтернативы

nginx Basic Auth, JWT в localStorage, OAuth через Google.

## Обоснование и последствия

Скрипты страницы не читают cookie, сервер может отзывать сессии, а реализация не требует внешних зависимостей. Basic Auth не интегрируется с UI портала.
