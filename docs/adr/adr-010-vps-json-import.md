# ADR-010: Import VPS from JSON in batches

- **Статус:** принято

## Контекст

Пакетный список серверов удобнее загружать из файла, чем создавать каждую запись отдельно.

## Решение

Поддерживать `POST /api/vps/import` для импорта VPS из JSON.

## Альтернативы

Добавлять записи только по одной через `POST /api/vps`.

## Обоснование и последствия

Файл обрабатывается одной пакетной операцией; невалидные записи и повторяющиеся имена пропускаются, результат возвращает счетчики.
