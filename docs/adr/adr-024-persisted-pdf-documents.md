# ADR-024: Persist imported renovation PDFs

- **Статус:** принято

## Контекст

Пользователям нужны ссылки на исходные PDF после импорта, а файлы должны переживать deployment.

## Решение

Хранить загруженные PDF в `RENOVATION_DOCS_DIR` (production: `server/docs/renovation`), выдавать через защищенный endpoint и отображать через pdf.js.

## Альтернативы

Не сохранять PDF, хранить только извлеченные данные или ссылаться на статический архив.

## Обоснование и последствия

UI связывает документы с исходными файлами; каталог сохраняется при deploy, выдача защищена авторизацией и path-traversal проверкой. Имена формируются детерминированно.
