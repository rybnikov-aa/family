# ADR-017: Keep the renovation schema in one source

- **Статус:** принято

## Контекст

Дублирование DDL между файлами создает риск рассинхронизации схемы.

## Решение

Определять схему renovation SQLite в блоке `SCHEMA` файла `db/renovationDatabase.ts`.

## Альтернативы

Дублировать DDL в нескольких файлах.

## Обоснование и последствия

`renovationDatabase.ts` остается единственным источником схемы. Данные поступают через PDF-импорт; HTML seed удален.
