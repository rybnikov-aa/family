# ADR-001: VPS configuration in SQLite

- **Статус:** принято

## Контекст

Список VPS требуется изменять во время работы приложения; статичный конфигурационный файл требует пересборки для обновления.

## Решение

Хранить VPS в SQLite через встроенный `node:sqlite`.

## Альтернативы

JSON/YAML/TOML/TypeScript-файл, `better-sqlite3`.

## Обоснование и последствия

Встроенная SQLite не добавляет зависимостей и позволяет изменять набор VPS без пересборки; позднее на этой основе можно хранить историю проверок.
