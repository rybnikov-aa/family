# ADR-023: Open the renovation project in the application

- **Статус:** принято

## Контекст

Карточка «Ремонт» должна вести на актуальные данные приложения, а не на архивные статические страницы.

## Решение

Использовать SPA route `/projects/renovation`, заданный во встроенном реестре `appProjects.ts`.

## Альтернативы

Оставить ссылку на статический HTML-архив.

## Обоснование и последствия

Статический `projects/renovation/` остается историей; seed и серверное зеркалирование архива не используются.
