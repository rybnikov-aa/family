# ADR-025: Match duplicate work items by section and position

- **Статус:** принято

## Контекст

Одинаковые наименования могут встречаться в разных разделах и повторяться внутри одного раздела; простое суммирование или сопоставление только по имени искажает отчет.

## Решение

Использовать ключ `раздел::имя`; дубликаты внутри раздела сопоставлять позиционно: i-я сметная позиция к i-му факту, лишние факты отмечать как `added`. В `normalizeName` игнорировать уточнения «толщиной»/«слоем».

## Альтернативы

Суммировать факт по всем дубликатам либо сопоставлять только по имени без раздела.

## Обоснование и последствия

Одинаковые работы в разных разделах остаются разными позициями; позиционное сопоставление сохраняет порядок сметы/акта и не завышает факт.
