# ADR-013: Isolate renovation data in its own database

- **Статус:** принято

## Контекст

Отчетность ремонта имеет собственную доменную модель и не должна смешиваться с конфигурацией VPS.

## Решение

Хранить данные ремонта в отдельной SQLite-базе `renovation.sqlite`, путь задается `RENOVATION_DB_PATH`.

## Альтернативы

Добавить таблицы в `DB_PATH` (`vps.sqlite`), хранить данные в JSON или использовать HTML как источник.

## Обоснование и последствия

Данные ремонта изолированы от хранилища VPS; обе базы включены в сохраняемые при деплое runtime-данные.
