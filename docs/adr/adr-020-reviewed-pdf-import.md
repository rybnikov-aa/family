# ADR-020: Review PDF drafts before database import

- **Статус:** принято

## Контекст

Автоматический разбор PDF не всегда точен, поэтому неподтвержденные результаты не должны сразу попадать в постоянное хранилище.

## Решение

Разделить импорт на загрузку/разбор черновика (`POST /pdf`) и подтверждение администратором (`POST /pdf/:id/confirm`).

## Альтернативы

Записывать результат парсинга в БД автоматически.

## Обоснование и последствия

Администратор проверяет черновик с `needsReview`. Повторный документ с номером заменяет прежнюю версию; для безномерных документов проверяется идемпотентность по типу и дате.
