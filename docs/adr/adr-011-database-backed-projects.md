# ADR-011: Store application projects in a registry and database

- **Статус:** принято

## Контекст

Пользовательские проекты должны создаваться и редактироваться без создания статических каталогов и публикации нового кода.

## Решение

Объединять встроенный реестр `appProjects.ts` с пользовательскими записями в SQLite `projects`; страницы отображаются маршрутами SPA.

## Альтернативы

Сканировать статические подпапки с `index.html` или создавать отдельные SPA/iframe.

## Обоснование и последствия

Создание через UI пишет запись в БД без файлов и деплоя. Статичный `projects/` остается историческим архивом и не участвует в выдаче проектов.
