> Снимок данных — 2026-09-18. Цены могут меняться: DeepSeek оставляет за собой право
> корректировать их, актуальные значения — на указанной странице. Документ необходимо
> **периодически актуализировать** из первоисточника (см. «Актуализация» ниже).

## Цены (за 1M токенов)

Токен — наименьшая единица текста, распознаваемая моделью (слово, число, знак
препинания). Счёт идёт по суммарному числу входных и выходных токенов.

| Цена (1,2,3)                    |          | deepseek-flash | deepseek-v4-pro |
| ------------------------------- | -------- | -------------- | --------------- |
| 1M входных токенов (cache hit)  | off-peak | $0.003         | $0.022          |
|                                 | peak     | $0.006         | $0.044          |
| 1M входных токенов (cache miss) | off-peak | $0.15          | $0.66           |
|                                 | peak     | $0.30          | $1.32           |
| 1M выходных токенов             | off-peak | $0.60          | $1.98           |
|                                 | peak     | $1.20          | $3.96           |
| Лимит конкурентности (4)        |          | 2500           | 500             |

Примечания:

1. **Peak/off-peak:** off-peak тарифы в два раза ниже peak. Пиковые часы —
   **01:00–04:00 и 06:00–10:00 UTC по будням (понедельник–пятница)**; все
   остальные часы — off-peak.
2. **Имена моделей:** актуальное имя Flash — `deepseek-flash` (версия DeepSeek-V4.1-Flash);
   прежние `deepseek-v4-flash` и `deepseek-v4-flash-vision-exp` **выведены из эксплуатации** —
   их запросы обслуживает DeepSeek-V4.1-Flash и тарифицирует по цене Flash. DeepSeek V4 Pro
   продолжает работу после 14.09.2026, тарификация без изменений.
3. **Vision — только Flash (`deepseek-flash`):** изображения конвертируются в
   токены по размерам и тарифицируются как входные токены вместе с текстовыми;
   `deepseek-v4-pro` vision не поддерживает.
4. Лимит конкурентности — подробнее: [Rate Limit & Isolation](https://api-docs.deepseek.com/quick_start/rate_limit).

## Правила списания

- **Расход = количество токенов × цена.**
- Средства списываются напрямую с пополненного или предоставленного баланса;
  при наличии обоих сначала расходуется предоставленный (granted) баланс.
- Перед пополнением сверяться с текущими ценами на странице
  [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/).

## Правило: проверка цен перед анализом

Правило применяется только при выбранной одной из моделей DeepSeek. В этом случае
перед началом анализа **любого** запроса пользователя:

1. Проверить текущую ценовую политику: актуальные цены и действующее окно
   peak/off-peak (пиковые часы — **01:00–04:00 и 06:00–10:00 UTC по будням (понедельник–пятница)**).
2. Если сейчас действует **peak-тариф** (цены высокие, вдвое выше off-peak) —
   вывести пользователю предупреждение о повышенной стоимости обработки
   запроса и **продолжать работу только после явного подтверждения** пользователя.
3. При off-peak предупреждение не требуется.
4. При модели не из DeepSeek правило не применяется.

## Актуализация из первоисточника

Ценовая политика может меняться. **Не реже одного раза в неделю** (и раньше, если
снимок подозрительно устарел) сверять `docs/pricing.md` с первоисточником:

1. Открыть [Models & Pricing | DeepSeek API Docs](https://api-docs.deepseek.com/quick_start/pricing/)
   и сравнить модели, цены (peak/off-peak, cache hit/miss, выходные токены) и лимиты
   конкурентности с текущим снимком.
2. При любых изменениях — обновить таблицы и **дату снимка** в шапке документа.
3. Если изменилось окно peak/off-peak — обновить его во всех местах
   (`docs/pricing.md`, правило 15 в `AGENTS.md`).
