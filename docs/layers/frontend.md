# Слой Frontend

Документ описывает общую архитектуру клиентского приложения. Поведение конкретных разделов, пользовательские сценарии и критерии приемки находятся в [доменных спецификациях](../domains/); визуальные токены и UI-примитивы — в [дизайн-системе](design-system.md).

## Стек и точки входа

- React 19, TypeScript и Vite; исходники — `frontend/src/`.
- `main.tsx` создает React root и оборачивает приложение в `StrictMode` и `AuthProvider`.
- `App.tsx` создает `createHashRouter`, применяет `AuthGate`, route layout и `AdminGate`; тяжелые страницы загружаются лениво.
- URL маршрутизация использует hash, так как production nginx не предоставляет SPA history fallback.

## Навигация и доступ

- Маршруты и их строковые константы определяются в `frontend/src/routes.ts`; новые внутренние маршруты регистрируются в `App.tsx`.
- `AuthGate` показывает вход до подтверждения сессии; `AdminGate` ограничивает UI административными маршрутами. Эти клиентские проверки дополняют, но не заменяют серверную авторизацию.
- Заголовок вкладки обновляется по текущему маршруту; бренд использует текущий hostname.

## Данные и API

- HTTP-запросы выполняются через `frontend/src/api/client.ts`; базовый URL — `VITE_API_BASE_URL` или `/api`.
- Общие структуры ответов и функции endpoint-клиента определяются API-контрактом в [api.md](api.md).
- Состояние загрузки/ошибок и повторная загрузка принадлежат hooks в `frontend/src/hooks/`; доменные хуки не должны обходить общий клиент.
- На HTTP 401 API-клиент отправляет `auth:unauthorized`; `AuthProvider` сбрасывает пользователя и возвращает приложение к экрану входа.

## Стили и пользовательский интерфейс

- Тема light/dark/system управляется через `useTheme` и CSS custom properties; избегать хардкода цветов.
- Глобальная точка входа стилей — `frontend/src/index.css`; правила размещаются в подходящих файлах `frontend/src/styles/`.
- UI-компоненты, токены, адаптивность и процедура проверки макетных изменений описаны в [дизайн-системе](design-system.md).
- Статические материалы в `projects/` являются историческим архивом, а не источником прикладной навигации или данных.

## Проверка

- Статическая проверка слоя: `npm run typecheck -w frontend`.
- Общий статический gate репозитория: `npm run typecheck`.
- Изменения пользовательского интерфейса проверяются в браузере по процедуре из `docs/layers/design-system.md`.
