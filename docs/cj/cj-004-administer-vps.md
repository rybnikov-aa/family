# CJ-004: Управлять списком VPS

- **Статус:** реализовано
- **Актор:** администратор
- **Цель:** менять набор серверов, проверяемых приложением, без редактирования файлов и рестарта backend.

## Путь

1. Администратор открывает детализацию VPS и выбирает добавление, редактирование, удаление или импорт JSON.
2. Для ручного ввода задает страну, имя, IP, ссылку панели и сервисы; сервис содержит имя, тип и адрес.
3. При сохранении backend валидирует входные данные; дубликат имени дает 409, невалидные поля — 400.
4. Для JSON администратор выбирает объект `{vps:[...]}` или массив; корректные записи импортируются, невалидные и дубликаты пропускаются с итоговыми счетчиками.
5. Для удаления подтверждает действие. Для редактирования форма предварительно заполняется текущими данными.
6. После успешной мутации runtime-конфигурация перечитывается, а UI обновляет статусы.
