# CJ-011: Отредактировать описание события и фотографии

- **Статус:** реализовано
- **Актор:** администратор
- **Цель:** написать подробный markdown-текст и встроить в него фотографии события.

## Путь

1. Администратор открывает фокусный редактор описания события.
2. Пишет markdown; справа видит предпросмотр (на мобильном — под редактором).
3. Вставляет доступные фото события кликом по миниатюре или загружает новое фото с диска/из Immich; для фото формируется маркер `diary-image://` у курсора.
4. Черновик автоматически сохраняется в localStorage; при уходе с несохраненными изменениями приложение просит подтверждение.
5. «Сохранить» сразу записывает описание на сервер; отдельного шага сохранения всей формы после этого нет.
