# CJ-017: Экспортировать событие дневника

- **Статус:** в реализации
- **Акторы:** авторизованный `user` или `admin`.
- **Цель:** сохранить событие или выбранные фотографии вне портала.

## Путь

1. Пользователь открывает страницу события.
2. Выбирает экспорт события в JSON или Markdown либо отмечает фотографии в галерее.
3. Для фотографий нажимает «Скачать выбранные».
4. Браузер скачивает файл события или оригиналы выбранных изображений.

## Ограничения

Экспорт не раскрывает внутренние пути БД, сессии и другие служебные данные. Доступ к событию
и изображениям сохраняется под авторизацией.
