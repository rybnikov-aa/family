# CJ-020: Установить и использовать портал на телефоне

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь.
- **Цель:** открыть семейный портал как приложение и продолжить просмотр при нестабильной сети.

## Путь

1. Пользователь открывает портал в поддерживаемом мобильном браузере.
2. Нажимает действие установки, если браузер предлагает install prompt.
3. После установки запускает портал с домашнего экрана.
4. Открывает ранее просмотренное событие дневника или его фотографию при временной потере сети.
5. Загружает новые фотографии через камеру телефона.

## Ограничения

Push-уведомления не считаются доступными до подключения server-side VAPID sender.
