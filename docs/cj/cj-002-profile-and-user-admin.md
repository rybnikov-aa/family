# CJ-002: Обновить профиль или управлять учетными записями

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь; администратор
- **Цель:** изменить личные данные или обслуживать учетные записи портала.

## Путь пользователя

1. Авторизованный пользователь открывает «Профиль» из шапки.
2. Меняет отображаемое имя и/или пароль; смена пароля требует текущий пароль, новый пароль — минимум 6 символов.
3. После успешного сохранения профиль обновляется; неверный текущий пароль или невалидные данные возвращают ошибку.

## Путь администратора

1. Администратор открывает панель пользователей с бейджа «админ».
2. Просматривает список, добавляет учетную запись с ролью `admin`/`user`, задает пароль, принудительно меняет пароль или удаляет пользователя.
3. Собственную учетную запись удалить нельзя; занятый username отклоняется конфликтом. Изменение роли существующего пользователя выполняется через CLI `npm run user -w backend -- set-role`, а не через web UI.
