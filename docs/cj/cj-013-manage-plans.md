# CJ-013: Планировать и отслеживать задачи

- **Статус:** реализовано
- **Акторы:** авторизованный `user` или `admin`; изменения доступны `admin`.
- **Цель:** создать задачу, связать её с проектом и отслеживать состояние.

## Путь пользователя

1. Пользователь открывает «Планы» с главной или через навигацию.
2. Приложение показывает задачи в группах по статусу.
3. Пользователь фильтрует список по проекту или приоритету.
4. На карточке видны описание, приоритет, срок и связанный проект.

## Путь администратора

1. Администратор нажимает «Новая задача».
2. Заполняет название, описание, статус, приоритет, срок и проект.
3. После сохранения задача появляется в соответствующей группе.
4. Администратор может изменить или удалить задачу с подтверждением удаления.
