# CJ-008: Применить дополнительное соглашение

- **Статус:** реализовано
- **Актор:** администратор
- **Цель:** пересчитать текущую смету с сохранением истории и контролем изменений.

## Путь

1. Администратор открывает смету и выбирает дополнительное соглашение.
2. Backend сопоставляет позиции по нормализованному имени и возвращает предложение: изменения, новые/сохраняемые позиции, итог.
3. Администратор проверяет diff и при необходимости задает ключи позиций для удаления.
4. После подтверждения текущая версия переводится в историю, новая версия становится current; суммы пересчитываются в копейках с учетом накладных.
5. UI обновляет смету и сводные отчеты.

## Альтернативы

Отмена до подтверждения не меняет БД; невалидная дата или отсутствующая смета/соглашение дают ошибку.
