# CJ-014: Найти запись глобальным поиском

- **Статус:** реализовано
- **Акторы:** авторизованный `user` или `admin`.
- **Цель:** быстро открыть нужный проект, план или событие дневника.

## Путь

1. Пользователь вводит минимум два символа в поле поиска в шапке.
2. Приложение открывает страницу результатов и сохраняет запрос в URL.
3. Результаты показывают тип записи, название, описание и метаданные.
4. Пользователь выбирает результат и переходит на внутреннюю страницу проекта, планов или дневника.
5. При отсутствии совпадений приложение показывает пустое состояние; ошибка API отображается явно.
