# CJ-006: Просмотреть отчетность ремонта

- **Статус:** реализовано
- **Акторы:** авторизованный `user` или `admin`
- **Цель:** ознакомиться со сводкой работ/материалов, версиями сметы и исходными PDF.

## Путь

1. Пользователь открывает встроенный проект «Ремонт» из каталога проектов.
2. Страница показывает сводку и данные из отдельной БД ремонта.
3. Пользователь открывает версии сметы, отчеты «Ход работ»/«Закупка материалов», ведомости и документы.
4. PDF открываются во встроенном просмотрщике; доступ к файлам защищен сессией.
5. Администратору дополнительно доступны редактирование метаданных, импорт и применение доп. соглашений.
