# CJ-005: Найти и открыть проект

- **Статус:** реализовано
- **Акторы:** авторизованный пользователь; администратор
- **Цель:** открыть прикладную страницу проекта и, если разрешено, изменить каталог.

## Путь пользователя

1. Пользователь открывает «Проекты» с главной или навигации.
2. Список объединяет встроенный реестр и записи пользовательских проектов; файловая система не сканируется.
3. Пользователь выбирает карточку и открывает SPA-маршрут `#/projects/<slug>`.
4. Встроенные проекты доступны для чтения, но не редактируются через CRUD.

## Путь администратора

Администратор может создать, изменить или удалить только проект, созданный через UI. Новый проект задает slug, название, описание, акцент, иконку, порядок и markdown-содержимое; запись сохраняется в БД без файлов и деплоя. Конфликт slug и ошибки валидации показываются пользователю.
