# CJ-022: Включить push-уведомления

- **Статус:** в реализации
- **Акторы:** авторизованный пользователь.
- **Цель:** получать новости и другие системные уведомления при закрытом приложении.

## Путь

1. Пользователь открывает портал в поддерживаемом браузере.
2. Нажимает «Включить push» и разрешает уведомления.
3. Браузер создаёт подписку, frontend отправляет её на backend.
4. Backend сохраняет подписку и использует VAPID sender для доставки.
5. Нажатие на уведомление открывает связанную страницу приложения.
6. При logout подписка текущего устройства отзывается или очищается при следующей проверке.

## Ограничения

Без настроенных VAPID-переменных уведомления не отправляются; UI показывает понятное состояние,
а browser reminders остаются отдельным локальным механизмом.
