# CJ-003: Проверить доступность VPS

- **Статус:** реализовано
- **Акторы:** авторизованный `user` или `admin`
- **Цель:** понять доступность серверов и конкретных сервисов.

## Путь

1. На главной пользователь видит рассчитанный процент доступности VPS и общий health backend.
2. Нажатие на VPS-карточку открывает модальное окно с серверами, странами, IP, процентами, сервисами и задержками.
3. Пользователь открывает ссылку на панель хостера либо копирует IP.
4. Кнопка обновления принудительно запускает проверку в обход 30-секундного cache; UI показывает состояние проверки.
5. Недоступность IP и отдельных сервисов отображается раздельно; формулы и состояния определены доменной спецификацией.

## Альтернативы

Если backend недоступен, интерфейс показывает ошибку/недоступность вместо ложного результата проверки. Мутационные действия доступны только `admin` и описаны в CJ-004.
