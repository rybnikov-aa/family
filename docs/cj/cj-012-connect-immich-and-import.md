# CJ-012: Подключить Immich и импортировать фотографии

- **Статус:** реализовано
- **Актор:** администратор
- **Цель:** настроить внешний фотоархив и при необходимости приложить оригиналы к событию дневника.

## Подключение

1. Администратор открывает настройки и задает base URL и API key.
2. Запускает проверку соединения; только успешная проверка сохраняет credentials в backend DB.
3. Клиент получает только base URL и состояние наличия ключа; сам API key не возвращается.
4. При наличии URL ссылка «Фотоархив» появляется на главной, а ссылка «Архив» — в футере.

## Импорт в событие

1. В форме события администратор выбирает «Из Immich», задает диапазон дат и просматривает результаты поиска.
2. Выбирает фото; приложение скачивает оригиналы через backend proxy, показывает прогресс и добавляет их как обычные файлы события.
3. Ошибка подключения, прав, отсутствующего ассета или превышения лимита размера показывается без падения формы; неподдерживаемые HEIC/RAW не предлагаются.
