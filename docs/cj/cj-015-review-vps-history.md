# CJ-015: Проверить историю доступности VPS

- **Статус:** реализовано
- **Акторы:** авторизованный `user` или `admin`.
- **Цель:** понять стабильность VPS за выбранный период и увидеть аварии.

## Путь

1. Пользователь открывает детализацию VPS на главной.
2. Нажимает кнопку «История доступности» у нужной VPS.
3. Выбирает период: 24 часа, 7 или 30 дней.
4. Приложение показывает процент доступности, среднюю задержку и график точек.
5. При наличии сбоев пользователь видит интервалы недоступности; если сбоев нет — подтверждение стабильности.

## Альтернативы

Если история ещё не накоплена, показывается пустое состояние. Если VPS удалена или API недоступен,
показывается сообщение об ошибке.
