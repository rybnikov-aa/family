# CJ-007: Импортировать PDF-документ ремонта

- **Статус:** реализовано
- **Актор:** администратор
- **Цель:** безопасно добавить смету, акт, заказ или ведомость в отчетность.

## Путь

1. Администратор открывает импорт PDF и выбирает локальный PDF (до 20 MiB).
2. Backend извлекает текст/таблицы, классифицирует тип, дату, номер и строит черновик.
3. Администратор проверяет распознанные сведения, позиции, суммы и предупреждения; при необходимости отменяет импорт.
4. При подтверждении данные записываются в БД, а PDF сохраняется в `RENOVATION_DOCS_DIR`.
5. Повторный документ с номером заменяет предыдущую версию; без номера срабатывает идемпотентность по типу и дате (409).

## Ошибки и отмена

Не-PDF, превышение размера, ошибка извлечения, истекший черновик и дубликат дают отдельные ошибки; неподтвержденный черновик не считается сохраненным документом.
